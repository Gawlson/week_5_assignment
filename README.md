# Knight Night

Base game created following this tutorial by Brackeys: https://www.youtube.com/watch?v=LOhfqjmasi0

Credits: https://kevins-moms-house.itch.io/camelot

## What We Added

Starting from the Brackeys base game, we added the following.

### Jules Quiñonez Novoa
- Art assets and wireframes for the game's UI
- Translation / localization support
- Main menu (`scenes/main_menu.tscn`)
- Options screen (`scenes/options.tscn`)
- UI spritesheet (`sprites/UI_spritesheet`)

### Gavin Wilson
- Pause menu (`pause.tscn` / `pause.gd`), about 2 hours of work
  - Toggle with Esc or P; pauses the game and shows an overlay
  - Resume, Options, Sound (mute/unmute), Save, and Main Menu buttons
  - Options opens Jules's options screen; Main Menu returns to her main menu

## Controls

| Key | Action |
|-----|--------|
| Space | Jump |
| Esc / P | Pause / resume |
